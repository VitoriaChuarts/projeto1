# 💧 Luz Irrigação — Landing Page Institucional

> Landing page institucional desenvolvida do zero para a empresa Luz Irrigação, utilizando HTML5 e CSS3.

## 📌 Sobre o projeto

O **Luz Irrigação** é uma landing page institucional criada para apresentar uma empresa do segmento de irrigação de forma organizada, clara e visualmente profissional.

A página reúne informações sobre a empresa, seus serviços, benefícios, depoimentos, galeria e formas de contato em uma única interface.

Este projeto foi desenvolvido como parte do meu processo de aprendizado em **desenvolvimento web**, colocando em prática os conhecimentos fundamentais de HTML5 e CSS3.

---

## 🎯 Objetivo

O objetivo do projeto foi criar uma landing page simples e profissional para apresentar a empresa e seus principais serviços.

Durante o desenvolvimento, o foco foi praticar:

* Estruturação de páginas HTML;
* Organização de conteúdo;
* HTML semântico;
* Criação de layouts com CSS;
* Alinhamento de elementos;
* Flexbox;
* Espaçamentos;
* Estilização de cards;
* Efeitos de interação;
* Organização dos arquivos do projeto.

---

## 🖥️ Estrutura da landing page

A página foi dividida em diferentes seções para apresentar as informações de forma organizada:

### 🏠 Início

Seção principal de apresentação da empresa, funcionando como o primeiro contato do visitante com a página.

### 👥 Sobre

Apresentação da empresa e de sua proposta.

### 🔧 Serviços

Apresentação dos principais serviços oferecidos pela empresa por meio de cards.

### ✅ Benefícios

Destaque dos principais benefícios e diferenciais apresentados pela empresa.

### ⭐ Depoimentos

Seção destinada à apresentação de avaliações de clientes.

> Os depoimentos utilizados no projeto são fictícios e foram inseridos exclusivamente para fins de demonstração visual.

### 🖼️ Galeria

Espaço destinado à apresentação de imagens relacionadas aos serviços e à empresa.

### 📞 Contato

Seção destinada às informações de contato da empresa.

### 🔻 Rodapé

Área final da página com informações complementares e links.

## 🛠️ Tecnologias utilizadas

### HTML5

Utilizado para construir a estrutura da landing page.

Foram praticados conceitos como:

* Estrutura semântica;
* `header`;
* `nav`;
* `main`;
* `section`;
* `footer`;
* `h1`, `h2` e `h3`;
* `p`;
* `ul` e `li`;
* Links;
* Imagens.

### CSS3

Utilizado para toda a estilização e organização visual da página.

Foram utilizados:

* Flexbox;
* `display: flex`;
* `justify-content`;
* `align-items`;
* `gap`;
* `margin`;
* `padding`;
* `width`;
* `border`;
* `border-radius`;
* Cores;
* `hover`;
* `transition`.

### Python

O Python foi utilizado apenas como **ferramenta de apoio durante o desenvolvimento**, para executar um servidor HTTP local e permitir a visualização da landing page durante os testes.

> O projeto não possui backend em Python. A landing page foi desenvolvida utilizando HTML5 e CSS3.
